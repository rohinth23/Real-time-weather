 🌦️ Real-Time Weather Analytics Dashboard

 📌 Project Overview
An interactive Real-Time Weather Analytics Dashboard developed using Microsoft Power BI. This project integrates weather data to monitor current weather conditions, analyze forecasts, and track air quality across multiple cities.

 🚀 Key Features
- Current temperature, humidity, and wind speed monitoring.
- 7-day weather forecast analysis.
- Air quality monitoring (PM2.5, PM10, CO, NO2, SO2, O3).
- Sunrise and sunset information.
- Interactive city selection and dashboard filters.

🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Weather API
- Data Visualization

 📊 Key Learnings
- API data integration
- Data cleaning and transformation
- Data modeling
- KPI development
- Interactive dashboard creation
